# 03 · Core：数值与状态机

代码：`src-tauri/src/core/state_machine.rs`（状态与仲裁）· `actions.toml`（数据表）· `obey.rs`（服从）· `bias.rs`（偏好）· `scheduler.rs` / `pomodoro.rs`（时间）· `food.rs`（货架）。
三层分工：**状态机**管合法转移与不变量；**驱力**（`decide`）管该做什么；**数据表**管每件事的消耗 / 收益 / 门槛 / 时段。`reduce(cat, shelf, pet, event)` 是纯函数。

## 1. 身上的数值

| 数值 | 范围 | 时间尺度 | 怎么变 |
|---|---|---|---|
| 体力 `strength` | 0–100 | 分钟 | 干活 −0.2~−0.5/min，发呆 +0.5，睡觉 +1.0；摸一下 −0.2 |
| 心情 `feeling` | 0–100 | 分钟 | 正事 −0.5~−1.25/min，玩 +0.5~+1.0，吃饭 +1.0；摸头 +1，摸身 +0.5；被逼急了 −2 |
| 饱腹 `hunger` / 口渴 `thirst` | 0–100 | 小时 | 随时间掉；一顿饭 +50（2 min）、一杯水 +35 |
| **健康 `health`** | 0–100 | 天 | 饱腹 / 口渴 / 体力 **< 30** 时每项每分钟 −0.05（三项全缺 5 个多小时从满掉到病线）；什么都不缺且 ≥ 50 时 +0.02/min（一天回 30）；**< 50 养不回来，只能喂药** |
| 药效 `remedy` | ≥ 0 | 小时 | 喂药进池子，每分钟吸收 0.5 进健康（阿司匹林 65 点两个多小时见效完） |
| 好感 `affection` | 0–100 | 天 | 摸头 +0.15（有额度：12 下腻，两小时回满）、听话 +0.3、**病中喂药 +0.5**、逼她 −0.5；向 40 指数回归（半衰期七天） |
| 钱 `money` / 经验 `exp` / 等级 | ≥ 0 | — | 工作赚钱、学习涨经验；`level = √(exp/100)`；效率看饱腹口渴（0.4–1.0） |

饿着 / 渴着 / 累着**同时**连带心情：每项 −0.05/min；**病着**（健康 < 50）心情再 −0.2/min（一小时 12）——所以她病了会明显蔫下去，不是只有面板上一根黄条。

## 2. 她怎么决定做什么（`decide`）

每一拍先看正在做的事该不该换（`should_switch`），该换才重新挑。优先级从上到下，第一个满足的胜出：

```
1. 生理急需        饱腹 < 20 → 吃 · 口渴 < 20 → 喝 · 体力 < 15 → 睡 · 心情 < 15 → 找乐子   （半夜也会爬起来，连冷却都不管）
2. 你让她做的事    保护期 directive（有期限） > 番茄钟 pinned_tag                            （生理这关过了就听它的）
3. 到点该做的      睡觉 23–8 · 三餐 7–9 / 11–13 / 17–19                                     （偏好排不过这一层）
4. 正事和玩        work / study / play 三条道按偏好重排；正偏置 ≥ 0.5 可越出时段；负偏置 ≤ −0.5 直接跳过
5. 数值提的要求    饱腹 < 35 · 口渴 < 35 · 心情 < 40 · 钱 < 80
6. 你的倾向        什么都不缺但你说过想让她多做点什么
7. 兜底            发呆（duration = 0，每一拍重新决策，随时起身）
```

**不抖的三处迟滞**：触发线低、解除线高（心情 15 去玩，涨到 35 才回去干活）；自己挑正事时体力要比门槛**高 8** 才开始；因前置条件掉了而放弃的活**冷却 15 分钟**。

**病重（健康 < 25）**：`bedridden` —— work / study / play 一律不选、正在做的立刻放下、使唤也不掷骰子直接拒绝。吃喝睡照常，病人也要吃饭。

**过场不打断**：吃、喝、收礼、吃药是 `is_transient`，做完才重新决策。

**吃什么**：货架来自 `assets-src/food/food.json`。开始吃 / 喝时只看对应分类，排掉药物，再过滤「买得起、能补当前需求」的项目，用状态里的时间和余额生成可复现种子随机挑一样并扣钱。随机数来自状态，所以同一次 `reduce` 永远得到同一结果；不同餐次不会永远固定成同一种食物。

## 3. 四种状态（→ 四套动画）

```
health  < 25                          → Ill            生病那套动画
strength < 20  或  feeling < 40       → PoorCondition  状态差
feeling ≥ 70   且  health ≥ 50        → Happy
其余                                   → Nomal
```

病着（健康 < 50）再开心也只到 Nomal——脸色摆在那里。Body 拿 `mood` 挑动画目录，没有对应心情的按 `happy → nomal → poorcondition → ill` 降级。

## 4. 健康与喂药

```
饿着 / 渴着 / 累着 ──> 健康往下掉 ──> < 50「生病」：面板黄条，心情大幅掉，自己养不好
                                       │
                                       ├─ 你喂药（托盘「喂她吃药」/ 面板「她生病了」卡片）
                                       │     Event::Medicated → 吃药动作（借「吃」的夹心动画，药片是食物精灵）
                                       │     药效进 remedy 池 → 每分钟吸收 0.5 → 健康慢慢回来 → ≥ 50 后又能自己养
                                       │
                                       └─ 不管 ──> < 25「病重」：Ill 动画，正事全停，只吃喝睡和发呆
```

- 药单是原版的十种 `Drug`，去掉白送的「太阳系」（体力 −100，救存档的彩蛋）。不指定就挑**刚好够补上缺口里最便宜的**（缺 30 → 大力丸 50 / ¥94，不是更贵的布洛芬），没有一种够就挑最猛的。
- 药自带的体力（钙片 +20）当场给；心情（大力丸 +50、脑黑金 −25）在两分钟的吃药动作里按分钟给。
- 没病（健康 + 药效 ≥ 100）时喂药她会说「我没生病呀」，不吃。
- 跨过病线会说一句（「……我好像有点不舒服」「头好晕」「好多了！谢谢你照顾我」），不开面板的人也知道她病了。
- 药是你出钱，不花她的——和礼物一样。

## 5. 服从判定（`obey::judge`）

用户的要求**不是命令**，是一次掷骰：

```
logit = 1.4（乖巧基线，σ ≈ 0.80）
      + 2.0 × (好感/100 − 0.5)
      + 1.6 × (心情/100 − 0.5)
      − 3.0 × Σ 冲突（饿 · 渴 · 累 · 心情差 · 病着，各自「多急 × 这件事帮不上忙 × 权重」）
      − 动作代价（全程掉 40 心情 = 1.0）
      − 0.6 × 压力（被拒后又反复要求的次数，半小时散完）
p = σ(logit)；roll < p 才答应
```

- 拒绝的理由 = 冲突最大的那一项 → 固定台词（饿 / 渴 / 累 / 心情差 / **不舒服** / 不太想 / 做不来）。
- 前置条件不满足是 `Impossible`（做不到，不是不听话）；病重是 `Sick`，都不掷骰。
- 第一次拒绝不收费；压力 ≥ 2 再逼才掉心情和好感。答应了压力清零、好感 +0.3。
- `request_action(target, minutes)` 是**唯一**用户意志入口；`target` 可以是动作 id 或 tag（`work` / `play` / `rest`）。

## 6. 保护期与偏好

- **保护期 `directive`**：答应了的事在一段时间内作息拽不走——你说的时长（≤ 240 min）/ 动作一轮（≤ 90）/ 不限时的给 20。生理急需照样压过。排在番茄钟前面。
- **偏好 `bias`**：「多工作一点」= 给 tag 一个带半衰期（默认 120 min）的权重。只在「正事和玩」那层重排、让正偏置越出时段；排不过生理急需和到点睡吃；吃喝睡不可压制（`SUPPRESSIBLE = work / study / play`）。

## 7. 时间

- **心跳**：每秒一拍；按墙上时钟算这一拍多长，待机醒来 / 重启补算（`catch_up`，封顶 120 分钟——离线衰减是「感觉时间过去了」，不是「你冷落了我」）。补算按 **5 分钟一片**走同一个 `reduce`，每片按往回推的钟点算：中途的决策点（心情崩了去玩、到点吃饭）和真跑时一样多，不会「一口气干两小时活」。
- **计时器**（`scheduler.rs`）：一次性 / 周期，落 `kv` 表，重启补发。**专注段** = 带起点和 target 的计时器：期间她去做 target，头顶挂倒计时环，到点 `focus:ended` + 提醒。
- **番茄钟**（`pomodoro.rs`）：25 / 5，四个一轮转长休 15，节奏可配；跑着时把她按在 work / rest 上（`pinned_tag`）。

## 8. 工具与权限（`tools.rs`）

Brain 动系统只有一条路：`run_tool` → 查注册表 → 权限门（`allow / ask / deny`，`origin = proactive` 门槛高一级；`ask` 目前当拒绝）→ 执行 → 落审计。已注册：计时器、番茄钟、`get_pet_state`、`request_action`、偏好、记忆六件套、`set_permission`。

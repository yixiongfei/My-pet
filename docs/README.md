## 一句话定义

> VPet 不是「桌宠 + AI」，而是**一个有身体的 Personal Agent**：
> 有状态、有记忆、能看懂你的工作 / 学习环境，通过自然语言陪你工作和学习。

身体是 UI，大脑才是产品。

## 现状盘点（2026-09-18）

**已经在桌面上跑的**（`启动桌宠.cmd` 一键起）：

- **身体**：当前本机 6875 帧动画由 `vup.json` 显式映射（`assets-src/`，不入库）→ WebP；透明置顶窗口、alpha 穿透、摸头 / 摸身 / 提起拖动、侧挂、自主走路爬墙；气泡浮在头顶，倒计时环挂在头顶；工作 / 学习 / 玩时在同类动画池里按驻留时长轮换。
- **神经系统（Rust）**：秒级状态机（体力 / 心情 / 饱腹 / 口渴 / 健康 / 好感 / 钱 / 经验），按 `actions.toml` 的作息自己吃饭睡觉上班学习玩；饿着渴着累着会伤健康，病了要你喂药；服从判定（对数几率）；偏好半衰期；保护期；计时器 / 番茄钟 / 专注段；长期记忆（SQLite + 语义向量）；全部纯函数 + 267 个单元测试。
- **大脑（本机）**：Ollama `qwen3.5:9b` 对话，角色卡 + 「此刻」+ 记忆进系统提示；「去玩会儿」「设个番茄钟学习一个小时」「十分钟后叫我」「多工作一点」由规则认出来直接进 Core；👍 / 修订可导出训练样本。
- **声音**：Qwen3-TTS（qwentts.cpp，核显 Vulkan）按句念对话回复、动作台词、答应 / 拒绝、收礼、生病；语气 / 语速 / 音调可调。
- **没做的**：模型调工具（AgentLoop）、Obsidian / 知识库 / GitHub 集成、主动行为与日常回顾、Tutor / Coach、云端模型、开机自启。完整清单见 06。

**本机环境**：Windows 11，Core Ultra 5 125H + Intel Arc 核显（无 CUDA），32 GB 内存；Rust stable、Node 24、pnpm 12、VS Build Tools；Ollama 与 TTS 引擎都由 `scripts/` 装在 `.runtime/`。

## 三条不动摇的设计原则

1. **对话驱动，而非设置驱动。** 配置仍然存在，但用户通过自然语言修改，不需要知道它在哪。
2. **LLM 是大脑，不是神经系统。** 计时、状态机、调度、权限校验、数据存取全部是确定性代码（Rust）。LLM 只做理解、规划、表达。
3. **陪伴 + 反馈 + 鼓励 + 适度提醒，不做电子监工。** 情绪引擎只正向放大，不惩罚——健康会掉，但那是「需要你照顾」，不是「你冷落了我」。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 透明窗口穿透在 Windows 上有坑 | 失败安全一律不穿透；托盘有「鼠标穿透」开关 |
| 内存紧张（对话 + 嵌入 + TTS 三个模型） | 启动脚本清掉孤儿 `llama-server`；Ollama 自己换出；对话偶尔多等几秒 |
| 缺动画 / 资源名对不上 | 播放器延迟回调 + 放弃计数；`hasClip` 先查 |
| 主动提醒变骚扰（未来） | Nudge Policy 全确定性；「别烦我」不经 LLM |
| 资产授权 | 个人使用；安装包不公开分发 |
